문서화 시작 시 코드 기준 커밋: `325dffa`. 다음 작업에서는 현재 브랜치와 diff부터 재확인합니다.

## 먼저 읽을 내용

- 목표: Android에서 테니스 영상을 업로드하고, 향후 동작·체형을 반영한 AI 분석과 3D 결과를 제공한다.
- 현재: 인증·영상·작업·결과 관리 기반은 구현돼 있다. 실제 AI 모델·학습·GPU 추론은 아직 없다.
- 사용자 우려: 환경 이전 때 코드 재작성을 최소화하고, DB·일반 서버·GPU 비용을 판단하고 싶다.
- 사용자 요청: 새 업무와 진행을 Markdown에 계속 기록하여 다음 대화에서 현황을 다시 설명하지 않게 한다.
- Render, Neon, Supabase, R2, RunPod, Modal은 비교한 후보다. 서비스 선택·유료 결제·이전은 확정되지 않았다.
- 2D 분석부터 시작하자는 것은 AI의 제안이다. 사용자가 기존 3D 목표를 축소하거나 변경하기로 결정한 것은 아니다.
- 실행·복원은 [운영 가이드](operations.md), 계획·장단점·비용·미결정 사항은 [로드맵](roadmap.md)을 읽는다.

## 상태와 진행도 기록 방법

| 상태 | 의미 |
| --- | --- |
| 미착수 | 업무는 등록됐지만 실제 작업을 시작하지 않음 |
| 진행 중 | 현재 실행 중인 작업이 있고 다음 실행 단계가 명확함 |
| 검증 대기 | 산출물은 준비됐지만 완료 기준 확인이 남음 |
| 사용자 결정 대기 | 명시된 선택이 필요함. 추천은 승인으로 취급하지 않음 |
| 차단 | 권한·외부 장애 등 구체적 사유로 진행 불가. 해소 조건을 기록 |
| 완료 | 해당 업무의 완료 기준과 검증 근거가 충족됨 |
| 보류 | 의도적으로 연기·중지됨. 이유와 재개 조건을 기록 |

진행도는 **완료한 확인 항목 수 / 등록된 확인 항목 수**다. 소요 시간이나 제품 완성률이 아니다.
항목 수를 바꿀 때는 이유를 활동 기록에 남긴다. 전체 제품의 임의 백분율은 산정하지 않는다.
아래 H 항목의 완료는 명시된 구현·조사 범위의 완료이며 상용 서비스 출시 완료를 뜻하지 않는다.

## 구현 경계와 다음 작업 시 주의할 사실

| 확인한 사실 | 후속 작업에 미치는 영향 |
| --- | --- |
| Flutter는 루트 `lib/`에 있고 `/app`은 없음 | 기존 feature-first 구조를 유지; 경로를 추정해 새 앱을 만들지 않음 |
| `backend/services/media.py`의 `BodyReconstructor`와 `UnconfiguredReconstructor`를 worker가 사용 | 모델 어댑터 경계를 재사용. 기본 실행은 실제 AI를 호출하지 않음 |
| `backend/routers/videos.py`의 `/api/v1/capabilities`는 `body_reconstruction=false`를 반환 | 실제 모델 연결 후 capability 응답도 실행 설정과 맞추고 회귀 테스트 필요 |
| `backend/worker.py`는 `asyncio.timeout(90)`과 작업 lease를 사용 | 수 분 걸리는 외부 GPU 작업은 단순 URL 연결만으로 완료되지 않음. 제출/대기/취소/lease 설계 필요 |
| 성공 작업 상태는 `succeeded`; 미연결은 `awaiting_model` | 대화에 사용한 `completed`를 API 값으로 구현하면 안 됨. 계약은 `backend/schemas/video.py` 확인 |
| worker의 기본 DB 조회 주기는 2초 | Neon 같은 유휴 중지 DB가 계속 활성화될 수 있음. 무료/간헐 비용을 그대로 적용하지 않음 |
| `Settings`는 `POSTGRES_*`로 URL을 만들며 `DATABASE_URL` 입력은 현재 없음 | 공급자 예제 환경변수를 그대로 붙이지 않음. API/worker와 `backend/migrations/env.py` 모두 검토 |
| DB 연결에 명시적인 TLS/CA/호스트 인증 설정이 없음 | 드라이버 기본 동작에 기대지 말고 운영 요구에 맞는 설정·테스트 추가 |
| `infra/compose.yaml`은 DB 호스트를 `postgres`로 덮어쓰고 로컬 DB에 의존 | `.env`만 변경해서 외부 DB로 이전된다고 가정하지 않음. 운영 배포 설정 필요 |
| `backend/core/storage.py`에 로컬/S3 구현이 있지만 실제 R2 사용은 미검증 | S3 호환성, multipart·Range·취소·삭제를 선택한 제공자에서 확인 |
| 영상과 GLB를 인증된 FastAPI 경로로 전달 | R2 송출 무료여도 API 호스팅 전송비가 남음. 서명 URL 도입은 별도 계약·권한 검토 업무 |
